## Отправить уже сохранённые файлы

В PowerShell из корня `web-log-project`:

```powershell
git status
git switch -c docs/save-release-metrics
git add docs/metrics/v0.1.0.json docs/metrics/v0.1.0-evidence docs/METRICS_GUIDE.md docs/metrics/README.md docs/LAB5_REPORT.md
git diff --cached --stat
git commit -m "docs: сохранить метрики версии 0.1.0"
git push -u origin docs/save-release-metrics
```

На GitHub открыть **Pull requests → New pull request**. Выбрать **base: main**,
**compare: docs/save-release-metrics**. Описание может быть коротким:
«Сохранены метрики и исходные отчёты успешного CI для версии 0.1.0».
После успешных проверок выполнить **Merge pull request → Confirm merge**.

Перечисленные команды добавляют только материалы метрик и отчёта. Локальное
изменение `.github/pull_request_template.md` остаётся отдельно. Word-отчёт
хранится вне репозитория, ФИО и учебные реквизиты в Git не добавляются.

## Как скачать следующий замер самостоятельно

1. Открыть **Actions → CI** и успешный запуск нужной версии. Для этапа лучше
   использовать тег на проверенном commit `main`.
2. Внизу страницы, в **Artifacts**, нажать `quality-reports-…` и распаковать ZIP.
3. Найти `metrics.json`. Проверить поля `commit`, `ref`, `pipeline_url`,
   `recorded_at_utc`; список `missing_reports` должен быть пустым.
4. Скопировать JSON в `docs/metrics/` с новым именем, например `increment-2.json`.
   Исходные `coverage.xml`, `junit.xml`, `ruff.json`, `complexity.json` сохранить
   в соседнем каталоге, например `increment-2-evidence/`.
5. Добавить строку с фактической датой, версией и значениями в таблицу отчёта.
6. Закоммитить снимок в отдельной ветке и слить через PR, как в примере выше.

Сохранённые снимки не редактировать под ожидаемые результаты. SHA внутри
снимка указывает на измеренный код; последующий docs-коммит будет иметь другой SHA.
В проекте артефакты Actions хранятся 30 дней, поэтому снимки сохраняются в Git.

Задание требует измерений при завершении этапов из лабораторной 3. Текущий
снимок фиксирует фактическое состояние прототипа 18.11.2026. Для прошедших
этапов без сохранившегося кода данные отмечаются как отсутствующие; плановые
даты не заменяют реальные даты измерений.

Официальная инструкция скачивания артефактов:
https://docs.github.com/en/actions/how-tos/manage-workflow-runs/download-workflow-artifacts
